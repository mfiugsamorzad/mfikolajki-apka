# czcionki/

Czcionka **DM Sans** (licencja SIL Open Font License), którą aplikacja wyświetla wszystkie napisy,
także polskie znaki.

| Plik | Zastosowanie |
|---|---|
| `DMSans-Regular.ttf` | zwykłe napisy: linia z FPS i skrótami klawiszowymi |
| `DMSans-SemiBold.ttf` | pogrubione napisy: nazwy gestów i efektów na kafelkach, „HO HO HO” |
