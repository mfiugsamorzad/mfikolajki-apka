# Czcionki

Wrzuć tutaj czcionkę **DM Sans** z https://fonts.google.com/specimen/DM+Sans
(**Get font → Download all**). Z pobranej paczki, z folderu `static/`, skopiuj **dwa pliki**:

- `DMSans-Regular.ttf` – zwykłe napisy,
- `DMSans-Bold.ttf` – pogrubione napisy (kafelki gestów, „HO HO HO”).

Pozostałe pliki (kursywa, inne grubości, warianty `18pt`/`24pt`/`36pt`) nie są potrzebne.
Zamiast tej pary może być też sam plik zmienny `DMSans-VariableFont_opsz,wght.ttf`.
